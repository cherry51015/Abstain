Evaluate a dispute

Documents go through extraction (rules first, the LLM only for what the rules can't read), a calibrated win-probability model, and an expected-value policy. ESCALATE happens only when a human review is worth more than it costs.

Contest
Expected recovery beats the contest cost, and a review would not change that.
Concede
Contesting loses money in expectation, or there is no time left.
Escalate
The value of a human resolving the uncertainty exceeds the review cost.
